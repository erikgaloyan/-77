# Прочный дом 77 — сайт строительной компании

Статический сайт строительной компании «Прочный дом 77», собранный по дизайн-макетам из Claude Design (claude.ai/design). Чистый HTML/CSS/JS, без сборки и зависимостей — открывается напрямую в браузере.

## Страницы

| Файл | Страница |
|------|----------|
| `index.html` | Главная — герой, услуги, преимущества, этапы работы, портфолио, форма заявки |
| `uslugi.html` | Услуги — детальное описание пяти направлений |
| `raboty.html` | Работы — портфолио объектов |
| `o-kompanii.html` | О компании — подход, преимущества, этапы работы |
| `kontakty.html` | Контакты — реквизиты, форма заявки, схема проезда |

## Ассеты

- `assets/styles.css` — дизайн-токены (тёмно-синяя брендовая палитра + янтарный акцент), базовые стили, компоненты (кнопки, карточки, бейджи, поля) и адаптивная вёрстка.
- `assets/app.js` — иконки (Lucide), мобильное меню, плавный скролл к якорям и валидация формы заявки.

Шрифты (Oswald, Golos Text) и иконки (Lucide) подключаются с CDN.

## Дизайн

- **Палитра:** брендовый тёмно-синий `#1B2A41` (шкала `--green-*`), сигнальный янтарный `#D9762B` (`--amber-*`), тёплые бетонные нейтрали.
- **Шрифты:** Oswald (заголовки, uppercase, «промышленный» характер) + Golos Text (текст, полная поддержка кириллицы).
- **Стиль:** индустриальный — скруглённые «на 6px» углы, приземлённые тени, мотив «шеврон-крыша» в логотипе и разделителях.

## Локальный запуск

Просто откройте `index.html` в браузере, либо поднимите статический сервер:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Фотографии

Сейчас на сайте стоят **брендовые заглушки** — SVG-файлы в `assets/img/`. Они входят в состав сайта (не зависят от интернета и всегда отображаются) и подписаны, какой кадр нужен в каждом месте. Замените их на свои фото: положите снимок в `assets/img/` и поменяйте `src` у соответствующего `<img>` — либо сохраните файл под тем же именем (например, `work-1.svg` → `work-1.jpg` и поправьте ссылку).

Что и где нужно снять:

| Место | Файл | Какой кадр нужен |
|-------|------|------------------|
| Обложка главной | `index.html`, `.hero__bg` | Общий план дома/стройплощадки — фактурно, «наша работа» |
| Обложка «Услуги» | `uslugi.html` | Кровельные/строительные работы в процессе |
| Обложка «Работы» | `raboty.html` | Готовый загородный дом целиком |
| Обложка «О компании» | `o-kompanii.html` | Бригада за работой на объекте |
| Обложка «Контакты» | `kontakty.html` | Дом/архитектура, спокойный кадр |
| Фото в «О компании» | `.about-photo` | Горизонтальный кадр стройки собственной бригадой |
| Портфолио (8 шт.) | `index.html`, `raboty.html` | По одному кадру на объект: фундамент, кровля, пристройка, фасад, бетонная площадка — крупно и аккуратно |

Рекомендации по съёмке: горизонтальные кадры, портфолио — соотношение ~4:3, обложки — ~16:9; хорошее дневное освещение; законченные, «чистые» объекты без строительного мусора в кадре.

## Что доработать под продакшн

- Форма заявки сейчас работает в демо-режиме (`assets/app.js`) — подключите реальный бэкенд/почтовый обработчик к `submit`.
- Замените референсные фото на свои и подставьте реальную карту проезда на странице «Контакты».
- Уточните реквизиты компании в футере и добавьте страницу политики конфиденциальности.
